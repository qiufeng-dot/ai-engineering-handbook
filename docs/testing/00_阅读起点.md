测试不是把程序运行几次，而是有理由地选择条件、观察行为，再判断这些观察支持了什么结论。黑盒方法从外部要求和输入输出关系设计测试；白盒方法利用程序内部的控制、数据或路径结构。它们提供两种互补的取证视角，并不对应“人工测试”和“自动测试”，也不分别等于“功能测试”和“性能测试”。

这套教材以三份指南和五篇研究资料为主线。指南帮助建立可操作的方法，研究论文帮助追问方法为什么有效、实验到底测到了什么、何时会失效。每篇都有独立讲解，最后用同一段业务规则把它们接起来。这里的“科研精读”指重建原文论证并审查证据；没有运行作者实验或证明某个真实产品已经通过测试。

<a id="section-1"></a>
## 先抓住四个连续的问题

假设系统规定：只有已登录、未被冻结，并且满足会员或优惠条件的用户，才能获得折扣。第一步是明确“应当如此”的依据，包括边界、例外和不合法输入。没有这一步，代码即使完全按自己写的逻辑执行，也可能实现了错误的规则。

第二步是从大量可能输入中选出值得测试的少数。按年龄、金额或状态分组，是利用对需求的理解；覆盖若干输入因素之间的组合，是利用对错误相互作用的假设。两种方法都会节省成本，也都会留下未被选择的输入。选择有依据，并不意味着剩余输入已被证明安全。

第三步是检查程序真正执行了什么。某个错误分支也许从未到达，某个子条件也许总被另一个条件遮蔽；结构覆盖能暴露这些空白。符号执行进一步尝试从代码反推能到达分支的输入。但即便到达全部已知目标，错误也可能没有传播到可见输出。

第四步是判断输出是否正确。这需要具体预期、性质、可信对照或人工评估。测试生成工具负责“找到并运行输入”，不自动负责“知道所有正确答案”。本书最后两篇正是为避免把执行范围误当成检错效果。

## 八份资料分别解决哪一段困难

| 阅读顺序 | 原始资料 | 你应能独立完成的事 |
|---|---|---|
| 1 | ISTQB CTFL v4.0.1 | 从规则构造等价类、边界、决策表和状态迁移测试，并交代覆盖分母 |
| 2 | NIST SP 800-142，2010 | 解释 t-way 覆盖、约束下的合法组合和为什么 pairwise 会漏掉高阶交互 |
| 3 | NASA MC/DC 教程，2001 | 为条件找到独立影响决策的配对，区分遮蔽与 unique-cause 解释 |
| 4 | Zhu、Hall、May，1997 | 读懂充分性准则、包含关系和“结构更强不必然检错更强”的条件 |
| 5 | King，1976 | 逐步维护符号状态、路径条件，并解释测试与证明的连接 |
| 6 | KLEE，2008 | 理解符号执行怎样处理约束成本、状态爆炸、外部环境及真实系统证据 |
| 7 | Inozemtseva、Holmes，2014 | 区分测试数量、覆盖、错误代理和因果结论，复算研究指标的分母 |
| 8 | Barr 等，2015 | 按判定依据选择 oracle，并识别形式规格、学习、差分和人工判断的失效条件 |

第一次学习可以顺序读 1–3，再读贯通练习，随后进入 4–8 的理论和研究证据。准备研究讨论时，先读 4、7、8，把“准则—实际效果—判定依据”连起来，再读 5、6，检查自动生成工具具体解决了哪一层问题。这只是阅读路线；每篇原文和全部讲义均保留。

<a id="section-3"></a>
## 为什么采用这些来源，以及“权威”该怎样理解

ISTQB 提供统一术语和基础技术；NIST 与 NASA 的技术报告给出较深入的工程方法；ACM 的综述与会议论文、USENIX 系统论文及 IEEE 综述提供形式定义、系统设计和实证证据。来源类型和出版时间都在各章标明。本文用它们建立方法基础，没有声称这是一份覆盖截至 2026 年全部最新研究的系统综述。

较老的材料仍能解释路径条件、组合覆盖等稳定概念，但不能单独说明今天任何工具的最新性能，也不能替代当前行业合规文件。NASA 教程中自身对政策和未定稿讨论的限制会在章内保留。对现实项目是否满足某项认证要求，本教材没有作出判断。

同样，来源可靠不表示每张图、每个公式都不会出错。本次核读遇到部分数字或图示与其说明不一致，已在相关章节标成“原文疑点”或“读者核算”，给出具体页码及可检查的推理；没有把修改后的结果悄悄当成作者原话。

<a id="section-4"></a>
## 阅读时怎样区分四种文字

原文的定义、数字和方法就近附页码链接；为补出中间步骤而写的推导，标为读者重建；自行设计的小程序或数值，标为教学例子；可能的后续实验，标为研究建议。这样你既能顺着讲义学，也能回到 PDF 检查关键断言。

PDF 链接中的页数按文件从第一页开始计数。有些技术报告还印有另一套页码，例如 NIST 与 NASA 正文的 PDF 页序通常比印刷页码大 6；相关章会说明。如使用作者稿或公开镜像，各章会注明对应版本；页码应以所链接的 PDF 为准。

<a id="section-5"></a>
## 读完的标准

你不需要背出八份资料的所有表格。你应能面对一个测试结论，追问它的输入怎么选、结构覆盖了哪里、正确答案从何而来、结果分母包含哪些对象、剩余风险是什么。面对一篇论文，还应能画出其论证链：研究问题怎样变成方法，方法怎样变成测量，测量又允许作者说出多强的结论。能完成这两件事，才算从术语学习走向研究阅读。
